# لعبة المافيا - نسخة ويب أوفلاين (PWA)

هذه إعادة بناء ويب مستقلة اعتماداً على ملف APK المرفوع. ليست عملية تحويل مباشر للـAPK ولا استعادة حرفية لكل ملفات Kotlin الأصلية. تم الاستناد إلى النصوص وبنية الكلاسات الظاهرة داخل الملف، ثم تنفيذ منطق اللعب من جديد. ملاحظة: الدور الهجومي الخاص في النسخة الأصلية أُعيد تصميمه هنا كـ«حارس الصالحين» بقدرة حماية إضافية واحدة.

## ما تتضمنه النسخة

- من 4 إلى 16 لاعباً على جهاز واحد بنظام تمرير الهاتف.
- توزيع أدوار عشوائي وموازنة تلقائية مع إمكانية تعديل الأدوار. تتضمن اللعبة 8 أدوار خاصة بالإضافة إلى المواطن الصالح (9 أنواع إجمالاً).
- شيخ المافيا، عضو مافيا، مافيا التسكيت، الطبيب، المحقق، عمدة الصالحين، الولد الصالح، حارس الصالحين، والمواطن الصالح.
- كشف دور سري لكل لاعب، ونقاش أول قبل الليل.
- أدوار ليلية خاصة، حماية الطبيب، فحص المحقق، قدرة الحارس الوقائية مرة واحدة، ورسائل سرية بين المافيا.
- نتائج الليل، لاعب مُسكت، نقاش نهاري، تصويت سري إجباري، تعادل وإعادة تصويت، دفاع وتغيير الأصوات، قدرة العمدة والولد الصالح، ونهاية الجولة.
- حفظ تلقائي محلي على الجهاز.
- Service Worker وملف Manifest لتثبيت التطبيق وتشغيله دون إنترنت بعد أول زيارة ناجحة.
- لا توجد مكتبات أو خطوط أو صور تُحمّل من الإنترنت أثناء اللعب.

## النشر المجاني على GitHub Pages

1. أنشئ مستودعاً عاماً جديداً على GitHub باسم مثل `mafia-offline-game`.
2. فك ضغط ملف ZIP على جهازك. ارفع **محتويات المجلد** إلى جذر المستودع، بما فيها مجلد `.github` وملف `index.html`.
3. افتح المستودع ثم `Settings` ثم `Pages`، واختر `GitHub Actions` كمصدر النشر.
4. افتح تبويب `Actions` وانتظر اكتمال مهمة `Deploy Mafia PWA to GitHub Pages` بنجاح.
5. افتح رابط GitHub Pages الناتج مرة واحدة على iPhone باستخدام Safari، واترك الصفحة تُحمّل بالكامل بينما الإنترنت متصل.
6. من Safari اضغط زر المشاركة ثم `Add to Home Screen` ثم `Add`.
7. افتح أيقونة اللعبة من الشاشة الرئيسية. بعد اكتمال أول تحميل وتخزين ملفات التطبيق، اختبرها بوضع الطيران.

## ملاحظات مهمة للآيفون

- تثبيت PWA لا ينتج ملف IPA؛ هو تطبيق ويب مثبت على الشاشة الرئيسية.
- يلزم HTTPS، لذلك لا تفتح `index.html` من مدير الملفات وتتوقع أن يعمل Service Worker أو التثبيت أوفلاين.
- يجب فتح اللعبة مرة واحدة على الإنترنت قبل استخدامها دون اتصال حتى تُخزّن ملفاتها.
- مسح بيانات Safari أو حذف الموقع قد يمسح نسخة التخزين المحلي والحفظ. لا تستخدم التصفح الخاص.
- حفظ اللعبة يعتمد على مساحة التخزين المحلية للمتصفح على الجهاز.

## اختبار محلي

يمكن فتح `index.html` مباشرة لمعاينة الواجهة، لكن خصائص التثبيت والعمل أوفلاين تحتاج استضافة HTTPS مثل GitHub Pages.

## ما لا يمكن ضمانه من APK وحده

ملف APK لا يحتوي مشروع Android الأصلي بشكل قابل للاستيراد مباشرة. لذلك لا يمكن ضمان استعادة كل تفاصيل التصميم أو كل سلوك داخلي لم يظهر في النصوص والموارد. هذه النسخة تعيد تنفيذ تدفق اللعبة والقدرات الأساسية بناءً على ما أمكن فحصه، وتحتاج تجربة لعب فعلية وملاحظاتك لتحسين أي اختلافات.
